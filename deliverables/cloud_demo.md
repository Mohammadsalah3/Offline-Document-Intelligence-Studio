\# Cloud Demo



A lightweight cloud demo of the project is available on Hugging Face:



https://huggingface.co/spaces/Mohdisleem3/offline-document-intelligence





\## Note



This deployment is only a demonstration version of the system.



Some components such as the local LLM and the trained ML model may be limited or disabled due to the resource constraints of the free cloud environment.



The full system with all features enabled is available in the local version included in this repository.
